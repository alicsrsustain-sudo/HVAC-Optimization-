HVAC Optimisation Calculators

A collection of Python-based engineering calculators for analysing and quantifying energy and cost savings in HVAC systems. Each tool models a specific optimisation measure, allowing engineers to compare current and proposed operating conditions and produce clear, auditable outputs.


Usage

Each file is self-contained. Open the file of interest, replace the input variables at the top with the real values from your case study (temperatures, flow rates, motor sizes, running hours, energy tariffs, etc.), and run:

bashpython <calculator_name>.py

No external dependencies are required beyond the Python standard library.
